## About This Project
This project analyzes 149 Bollywood movies to identify key factors that determine box office success and predict whether a movie will be a Hit or Flop using Machine Learning.

## Key Findings
- 55.7% of Bollywood movies in this dataset were profitable
- Drama and Action are the most profitable genres
- YouTube Likes is a stronger predictor of success than budget
- Random Forest model predicts Hit or Flop with 67% accuracy

## Features
- 🎯 Interactive Hit/Flop predictor with sliders
- 📊 Data visualizations and insights
- 🏆 Top 10 most profitable movies
- 🔥 Correlation heatmap
