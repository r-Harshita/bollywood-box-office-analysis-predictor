## About This Project
This project explores what makes a Bollywood movie successful 
using data analysis and machine learning.

## Key Findings
- 55.7% of Bollywood movies in this dataset were profitable
- Drama and Action are the most profitable genres
- YouTube Likes is a stronger predictor of success than budget
- A Random Forest model predicts Hit or Flop with 67% accuracy

## Project Structure
- Data Cleaning & Feature Engineering
- Exploratory Data Analysis
- Data Visualization (5 charts)
- Machine Learning Model
- Interactive Hit/Flop Predictor

## How To Run
1. Clone this repository
2. Install requirements: 
   pip install pandas matplotlib seaborn scikit-learn jupyter
3. Open "The Bollywood Project.ipynb" in Jupyter Notebook
4. Run all cells
